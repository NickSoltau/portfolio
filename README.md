# Nick Soltau - Portfolio

**Live site:** https://portfolio-mu-khaki-39.vercel.app

My frontend developer portfolio: projects with live demos, my background, and how to reach me.

## Built with

Next.js (App Router), React, Tailwind CSS v4, and Motion for animations. Dark mode follows the visitor's system setting, and a saved choice wins. The contact form sends through Web3Forms.

## Projects shown

- **CraftDesk** - booking and payments app for small service shops
- **Summarist** - book-summary app with sign-in and subscriptions
- **Ultraverse NFT Marketplace** - a starter template I built out into a working app with live API data
- **Skinstric** - AI skincare analysis app built from Figma designs

## Run it locally

```bash
git clone https://github.com/NickSoltau/portfolio.git
cd portfolio
npm install
npm run dev
```

Then open http://localhost:3000.
